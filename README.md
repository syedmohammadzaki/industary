# 🏭 Industary Website

A responsive industrial business website built as a front-end development practice project. The design focuses on a clean, professional industrial aesthetic with structured sections, navigation, services, and visual content.

🌐 **Live Website:**
https://syedmohammadzaki.github.io/industary/

## 📌 About the Project

**Industary** is a front-end website inspired by modern industrial and manufacturing business websites.

I created this website as part of my journey in learning **HTML and CSS**, focusing on building layouts, organizing website sections, styling components, and making the design responsive across different screen sizes.

## ✨ Features

* Responsive website layout
* Professional industrial-style design
* Navigation bar
* Hero section
* About section
* Services section
* Project and content sections
* Image-based layouts
* Buttons and hover effects
* Custom typography using Google Fonts
* Font Awesome icons
* Responsive CSS styling

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **Google Fonts** – Typography
* **Font Awesome** – Icons
* **GitHub Pages** – Website hosting
